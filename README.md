# 📊 AI Data Analyst Agent

An AI-powered data analysis web application that allows users to upload datasets and automatically generate insights, visualizations, and reports using Artificial Intelligence.

---

## 🚀 Overview

The **AI Data Analyst Agent** is a dynamic system designed to simplify data analysis.  
It combines **data cleaning, visualization, and AI-based reasoning** into a single platform.

Users can upload any dataset (CSV/Excel), and the system will:
- Clean the data
- Generate charts
- Provide AI-driven insights
- Export reports (PDF)

---

✔ Automatic Data Cleaning

- Scatter Plot  
- Pie Chart  
- Histogram  
- Box Plot  
- Count Plot  

---

## 🤖 AI Capabilities

- Generates insights based on selected data  
- Explains patterns and trends  
- Works dynamically on any dataset  
- Uses LLM-based reasoning  

---

## 🧠 How It Works

1. Upload dataset (CSV/Excel)  
2. Data is cleaned automatically  
3. Select columns and graph type  
4. Visualization is generated  
5. AI analyzes the data  
6. Insights are displayed  
7. PDF report is generated
